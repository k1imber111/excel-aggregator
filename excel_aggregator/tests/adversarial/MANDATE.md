# Мандат красной команды — «Агрегатор Excel-таблиц»

## Что делает программа
Консольное приложение собирает характеристики одних и тех же объектов из
нескольких файлов Excel (.xls/.xlsx) в один .xlsx. На каждом листе оно само
находит таблицу (шапку, начало данных), столбец с названиями объектов, и
соединяет таблицы по этим названиям. Итог: строка 1 — название, строка 2 —
имена файлов, затем шапка как в исходниках (объединения, переносы строк),
затем данные с форматами чисел исходников.

## Главные инварианты (их и надо ломать)
1. Значение каждой ячейки итога — это значение того же объекта из того же
   столбца исходника. Съезд строки, чужой объект, чужой столбец — критично.
2. Ни одно значение не теряется молча и не меняет тип/вид: числа — числами,
   текст — текстом (в том числе «040», «51.30»), даты — датами, формат числа
   исходника («0.0», «0%», дата) переносится.
3. Шапка итога повторяет структуру шапки исходника: объединения, переносы
   строк, многоуровневость; однострочная — однострочная.
4. Строки-подписи, итоги, нумерация граф, подпись над таблицей объектами не
   становятся; настоящие объекты не теряются.
5. Программа не падает с необработанным исключением на любом .xls/.xlsx и
   не портит исходные файлы.

## Правила
- Production-код (`excel_aggregator/core`, `excel_aggregator/app.py`,
  `main.py`) НЕ править. Писать только тесты в
  `excel_aggregator/tests/adversarial/test_<зона>_adversarial.py`.
- Каждая находка — отдельный pytest-тест, который ПАДАЕТ на текущем коде по
  существу (не из-за опечатки в тесте). Без skip/xfail.
- Входные файлы создавать в `tmp_path` через openpyxl (xlsx) или строить
  `SheetGrid` напрямую (`from excel_aggregator.core import SheetGrid`;
  merged — кортежи (rlo, rhi, clo, chi), rhi/chi не включены). xlwt не
  установлен — .xls не создавать.
- Реальные примеры (только чтение): `Примеры таблиц/*.xls`.
- Запуск только своего файла:
  `PYTHONIOENCODING=utf-8 timeout 180 .venv/Scripts/python.exe -m pytest excel_aggregator/tests/adversarial/<файл> -q -p no:cacheprovider --tb=line | tail -40`
- Полный набор тестов не запускать.
- Чекпоинт после каждого прогона:
  `excel_aggregator/tests/adversarial/_scratch/<файл>.checkpoint.md`.
- Код читать через `grep -n` и Read с offset/limit (≤120 строк за раз).
- ~40 вызовов инструментов; отчёт ≤ 700 слов: находки (тест, 1–3 строки
  вывода, влияние), векторы, которые выдержали.
- Ожидаемое поведение, которое не баг: повтор названия внутри файла — берётся
  первая строка с предупреждением; числа, записанные текстом, остаются текстом;
  скрытые листы пропускаются, если есть видимая таблица.
