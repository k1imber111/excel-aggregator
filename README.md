# Агрегатор Excel-таблиц

Консольное приложение для Windows, которое собирает характеристики объектов
из нескольких файлов Excel (`.xls` и `.xlsx`, любых годов) в один итоговый
файл. Связь таблиц — по общему столбцу (или строке) с названиями объектов.

Автор: Иван Журавлев.

## Запуск готовой программы

Готовый файл — `dist\Агрегатор таблиц.exe`. Он самодостаточен: Python и
библиотеки вшиты внутрь, установка и права администратора не нужны.
Запуск — двойным кликом или из командной строки.

При запуске доступны «Инструкция» (подробное описание работы) и
«Запуск программы» (пошаговая настройка). На каждом шаге действуют команды:
`н` — назад, `с` — собрать файл, `о` — отмена (выход в главное меню).

## Как это работает (кратко)

1. Укажите путь к первому файлу (пути с кавычками, относительные и без
   расширения обрабатываются автоматически), выберите листы.
2. Укажите координату начала названий объектов (например, `A6`) и их
   направление (вертикально/горизонтально) — программа дочитает значения
   до конца, пропуская пустые ячейки, покажет их количество и первые пять.
3. Выберите столбцы с характеристиками для переноса — можно вводить отдельные
   номера и диапазоны, например `2-5, 8`; их названия программа
   прочитает из заголовков таблицы сама (включая единицы измерения);
   спросит название, только если заголовок найти не удалось.
4. Добавляйте остальные файлы: в каждом программа сама ищет столбец
   с названиями и просит лишь подтвердить вариант (или указать вручную).
5. «Собрать файл» — итоговый `.xlsx` со всеми названиями объектов из всех
   файлов: каждая характеристика — отдельный столбец без префикса имени файла
   или листа, оформленная таблица (перенос текста, автоширина, высота строк,
   границы, закреплённая шапка, автофильтр). Если на пути сохранения нажать
   Enter, файл будет сохранён рядом с программой.

Объединённые ячейки, разные шрифты и форматы, числа-записанные-текстом —
обрабатываются корректно. Исходные файлы не изменяются.

## Разработка

Требуется Python 3.12 (код совместим с 3.10–3.12).

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest excel_aggregator/tests -q   # тесты
python main.py                                # запуск из исходников
build.bat                                     # сборка exe в dist\
```

## Структура проекта

```
main.py                    # точка входа
excel_aggregator/
  app.py                   # машина состояний (шаги настройки)
  ui/                      # консольный интерфейс (rich)
  core/                    # чтение Excel, ключи, автопоиск, агрегация, экспорт

build.bat                  # сборка exe

wiki/                      # проектная wiki (план, анализ примеров, журнал)
```
