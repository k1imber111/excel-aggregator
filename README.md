# Агрегатор Excel-таблиц

Консольное приложение для Windows, которое собирает характеристики одних и
тех же объектов из нескольких файлов Excel (`.xls` и `.xlsx`, любых годов) в
одну итоговую таблицу. Таблицы соединяются по столбцу с названиями (номерами,
кодами) объектов.

Программа работает в полуавтоматическом режиме: сама находит на листе
таблицу, её шапку, начало данных и столбец с названиями объектов. От
пользователя нужны файлы и подтверждение найденного.

Автор: Иван Журавлев.

## Запуск готовой программы

Готовый файл — `dist\Агрегатор таблиц.exe`. Он самодостаточен: Python и
библиотеки вшиты внутрь, установка и права администратора не нужны.
Запуск — двойным кликом или из командной строки.

## Как работать

```
Главное меню: 1 Начать работу · 2 Инструкция · 3 Выход

Шаг 1. Файлы ──── путь к файлу, к папке или несколько путей; Enter — дальше
Шаг 2. Проверка ─ что программа нашла в каждом файле; Enter — всё верно
Шаг 3. Столбцы ── что перенести из каждой таблицы; Enter — всё
Сборка ────────── имя файла; Enter — «Агрегированная таблица.xlsx»
```

Типовой случай: вставить путь к папке с таблицами и четыре раза нажать Enter.
Ещё быстрее — перетащить файлы или папку мышью на значок
`Агрегатор таблиц.exe`: программа откроется сразу на шаге 1 с этими файлами.

1. **Файлы.** Укажите путь к файлу или к папке (берутся все `.xls`/`.xlsx`).
   Путь можно перетащить мышью в окно; кавычки, относительные пути и путь без
   расширения обрабатываются сами. Чтобы убрать файл из списка — `-2`.
2. **Проверка.** Для каждого файла программа показывает лист, строки шапки,
   строки данных, столбец с названиями объектов, сколько названий найдено и
   сколько из них общих с другими таблицами, а также первые и последние
   названия. Если программа ошиблась — «Изменить источник»: первая строка
   данных, столбец названий, другой лист, повёрнутая таблица.
3. **Столбцы.** Список столбцов с полными названиями. Enter — перенести все;
   либо номера: `2,4`, `2-5`, `кроме: 3`. Лист не нужен — `п` (пропустить):
   он не попадёт в итог, программа сразу покажет следующий лист. Пропустить
   можно любой лист, кроме последнего оставшегося; вернуться к нему — `н`.
4. **Сборка.** Программа записывает файл, перечитывает его и сверяет с
   исходными данными, затем показывает отчёт.

На каждом шаге действуют команды: `н` — назад, `с` — собрать файл,
`о` — отмена (выход в главное меню); на шаге 3 ещё `п` — пропустить лист
(также «далее»).

## Что умеет распознавать

- Шапку в несколько строк с объединёнными ячейками. Название столбца
  собирается цепочкой сверху вниз: «Прямоугольные координаты, м → ИВПП 06/24 →
  МКпос=058º → X».
- Шапку без объединений, шапку в одну строку, таблицу без шапки (столбцы
  получают названия «Столбец B»).
- Группу, не объединённую в исходнике: «Высота» над «м» и «фут» даёт
  «Высота, м» и «Высота, фут».
- Единицы измерения в отдельной строке («град», «мин», «м», «фут», `°`).
- Подпись над таблицей, строку нумерации граф (1, 2, 3…), строки-разделители
  («район 2»), строки итогов и примечаний — объектами они не становятся.
- Числа, записанные текстом, и текст, записанный числом; лишние пробелы и
  переносы строк в названиях; даты.
- Столбец, по которому соединять таблицы: по совпадению значений между
  файлами. Столбцы измерений и нумерация строк «1…N» названиями не считаются.

## Итоговый файл

- Строка 1 — название таблицы (имя файла).
- Строка 2 — над каждым блоком столбцов имя файла, из которого он взят.
- Далее — шапка каждого исходника как есть: те же объединённые ячейки, те же
  уровни, переносы строк внутри заголовков. Однострочная шапка остаётся
  однострочной. Шапки разной высоты выравниваются: нижние заголовки
  растягиваются вниз. Подпись над таблицей, строка нумерации граф (1, 2, 3…)
  и подпись раздела в строке единиц («4 Препятствия») в итог не переносятся.
- Формат чисел и дат — как в исходнике: `41189.1` при формате `0.0`, проценты,
  даты. Числа, записанные в исходнике текстом («040», «51.30»), остаются
  текстом.
- Автофильтр на нижней строке шапки; шапка и первый столбец закреплены.
- Ширина столбцов подобрана по виду данных и словам заголовка; длинные
  заголовки переносятся. Строки данных обычной высоты, выше — только если
  текст действительно переносится. Границы у всех ячеек.
- Названия объектов из одних цифр записаны числами: фильтр сортирует
  `1, 2, 10`, а не `1, 10, 2`.
- Печать: альбомная, по ширине страницы, шапка на каждом листе.

## Защита от ошибок

- Найденное подтверждает пользователь; видны первые и последние названия.
- Предупреждения: мало общих названий, повторы (с номерами строк), ячейки с
  ошибками (`#REF!`), формулы без сохранённого значения, названия объектов из
  столбцов с разными заголовками.
- Если общих названий нет, программа не соединяет таблицы по случайному
  совпадению чисел, а сообщает об этом.
- Названия, отличающиеся только латинскими и русскими буквами (`A` и `А`),
  не сливаются молча: программа спрашивает.
- После записи файл перечитывается и сверяется с данными ячейка в ячейку,
  включая формат чисел.
- Скрытые листы книги пропускаются, если в ней есть видимая таблица; на шаге 2
  видно, сколько скрытых листов пропущено. Скрытый лист можно добавить вручную:
  «Изменить источник → Добавить другой лист».
- Итоговый файл нельзя сохранить поверх исходного.
- Непредвиденная ошибка не сбрасывает настройку: программа предлагает
  повторить шаг и пишет подробности в `aggregator_error.log` рядом с собой.
- Исходные файлы не изменяются.

## Известные ограничения

- Автораспознавание рассчитано на таблицы «один объект — одна строка».
  Повёрнутую таблицу нужно отметить вручную на шаге 2.
- Подвал с заполненными соседними ячейками («Исполнитель: … | подпись»)
  отличить от объекта нельзя — он виден в «последних названиях» на шаге 2.
- Формулы `.xlsx` без сохранённого значения читаются пустыми (программа
  предупреждает и просит пересохранить файл в Excel).
- Дефисы переноса в заголовках («Широ-та») сохраняются как в исходнике.
- Строка «1 | 2 | 3» прямо под шапкой считается нумерацией граф: её не
  отличить от первого объекта из маленьких чисел. На шаге 2 в столбце «Шапка»
  видно, какая строка принята за нумерацию.
- Строка из одного названия в несколько слов без характеристик («Опора 77»)
  неотличима от подписи «район 2»: в итог не идёт, но показана в
  предупреждении «строки-подписи пропущены».
- Узкую текстовую таблицу (до трёх столбцов, без чисел), где значение в
  данных объединено по вертикали, программа может не распознать — тогда она
  попросит указать первую строку данных.
- Числа, записанные в исходнике текстом, остаются текстом (Excel помечает их
  зелёным треугольником). Целые длиннее 15–16 цифр пишутся текстом, чтобы не
  потерять цифры.

## Разработка

Требуется Python 3.12 (код совместим с 3.10–3.12).

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest excel_aggregator/tests -q   # тесты
python main.py                                # запуск из исходников
build.bat                                     # сборка exe в dist\
```

## Структура проекта

```
main.py                    # точка входа
excel_aggregator/
  app.py                   # сценарий: файлы → проверка → столбцы → сборка
  ui/                      # консольный интерфейс (rich)
  core/
    reader.py              # чтение .xls/.xlsx в сетку листа
    layout.py              # распознавание шапки, начала данных, названий столбцов
    matcher.py             # выбор столбца, по которому соединять таблицы
    keys.py                # названия объектов, повторы, строки-подписи
    normalize.py           # приведение названий к одному виду
    aggregator.py          # сборка итоговой таблицы
    exporter.py            # запись .xlsx и проверка записанного
  tests/                   # unit-, сценарные и e2e-тесты
build.bat                  # сборка exe
«Агрегатор таблиц.spec»    # конфиг PyInstaller
wiki/                      # проектная wiki (положения разработки, журнал)
Примеры таблиц/            # неизменяемые исходные примеры
```

Подробности — в `wiki/index.md`.
